# BanID

BanID – desktop-приложение, разработанное на языке C# с использованием технологии WPF.

Приложение предназначено для работы пользователей с банковскими данными. В программе реализована авторизация и регистрация пользователей, просмотр информации о счетах и вкладах, работа с заявками, а также отдельный интерфейс для администратора.

## Возможности приложения

Основные возможности программы:

- регистрация новых пользователей;
- авторизация пользователей;
- просмотр банковских счетов;
- просмотр информации о вкладах;
- создание и просмотр заявок;
- работа с персональными данными пользователя;
- отдельный интерфейс для администратора;
- подтверждение и отклонение заявок администратором.

## Установка

Для работы с проектом необходимо:

1. Установить Microsoft Visual Studio.
2. Открыть файл решения `BanID.slnx`.
3. Дождаться загрузки проекта и необходимых зависимостей.
4. Собрать проект.
5. Запустить приложение средствами Visual Studio.

Проект разработан как WPF-приложение на языке C#.

## Использование

После запуска приложения открывается окно авторизации.

Пользователь может войти в существующую учётную запись или перейти к регистрации нового аккаунта.

После успешной авторизации открывается основной интерфейс приложения. Доступные функции зависят от роли пользователя.

Обычный пользователь может работать со своими банковскими данными и заявками. Администратор имеет доступ к просмотру и обработке заявок пользователей.

## Структура проекта

Проект разделён на несколько основных каталогов:

- `Models` – модели данных и основные сущности приложения;
- `Pages` – страницы пользовательского интерфейса;
- `Services` – классы для работы с данными и безопасностью;
- `Windows` – отдельные окна приложения;
- `App.xaml` – настройки и точка запуска WPF-приложения;
- `MainWindow.xaml` – главное окно приложения.

Такое разделение позволяет сделать структуру проекта более понятной и упрощает поиск необходимых файлов.

## Данные

Приложение работает с данными пользователей, банковских счетов, вкладов и заявок.

Для работы с данными используется отдельный сервис, который выполняет необходимые операции и передаёт полученную информацию страницам пользовательского интерфейса.

Персональные данные и данные для авторизации обрабатываются с использованием отдельного сервиса безопасности.
